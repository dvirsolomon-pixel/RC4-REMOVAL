## נכס פתיחה
בריפו כבר קיים מוצר עובד: `Manage-KerberosEncryption.ps1` — כלי PowerShell לאיתור וטיפול בהצפנת RC4 חלשה ב-Kerberos ב-Active Directory.
זה מעיד על יכולת ליבה של המייסד: **אבטחת תשתיות Microsoft / Active Directory**. ניתוח השוק בודק גם את הכיוון הזה וגם חלופות רחבות יותר.
